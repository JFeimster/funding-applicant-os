03 / HOW THE MACHINE WORKS

FORWARD THE EMAIL. MOVE THE RECORD. WATCH THE EXCEPTIONS.

The working Cloudflare → Vercel path does not require Gmail polling or n8n. Each system reports its own processing result.

STEP 01 / FORWARD

SEND THE SIGNAL

An operator forwards an applicant notification to the private intake mailbox. Cloudflare accepts it and delivers the message to the Email Worker.

STEP 02 / ROUTE

CLASSIFY + MATCH

Vercel's intake router classifies the message, parses applicant details, and resolves existing identities before writing.

STEP 03 / RECONCILE

SYNC + VERIFY

HubSpot, Notion, and Google Sheets receive upserts. Partial failures and ambiguous matches are surfaced for operator review.
