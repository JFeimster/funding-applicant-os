03 / HOW THE MACHINE WORKS

EMAIL ARRIVES. THE MACHINE TAKES IT FROM THERE.

Three moves: capture the signal, orchestrate the record, move the file. The human stays available for the messy part.

STEP 01 / CAPTURE

READ THE SIGNAL

Gmail detects a qualifying funding event and parses the applicant, route, status, source, and useful operational context.

STEP 02 / ORCHESTRATE

WRITE THE RECORD

n8n normalizes the payload, checks HubSpot for existing records, applies dedupe logic, and updates or creates the deal.

STEP 03 / MOVE

QUEUE THE NEXT ACTION

The system assigns priority, next step, and follow-up tasks while surfacing exceptions that need a human.
